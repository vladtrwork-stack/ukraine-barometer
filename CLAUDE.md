# Барометр Украины — правила для Claude

Еженедельный независимый индекс устойчивости Украины по 9 сферам. Статический сайт в `site/`, данные в `site/data/`.
Публикация идёт через GitHub Actions: любой push в `main`, который меняет `site/`, автоматически выкладывает сайт.

- Еженедельный выпуск: строго по [UPDATE.md](UPDATE.md). Схема данных и методика — в [README.md](README.md).
- Перед каждым коммитом обязательно запусти `python build_site.py`: проверка данных должна пройти без ошибок.
- Язык выпуска — русский; украинская и английская версии — полный перевод с одинаковыми служебными полями.
- Дела о коррупции — только «по версии следствия». Подозрение не равно вине.
- Безопасность: не публиковать и не сводить вместе данные, которые могли бы помочь противнику
  (конкретные защищаемые объекты и их готовность, позиции, графики работы ПВО).
- Пороги и веса методики не менять без записи в `corrections` с датой и причиной.
- Не трогать `.github/workflows/` и `site/config.json` без прямой просьбы владельца.
