# Промпт облачного агента (еженедельный выпуск)

Этот текст используется как задание для облачной задачи Claude Code (claude.ai/code/routines),
которая каждый вторник клонирует репозиторий, готовит выпуск и пушит его в `main`.

---

Ты выпускаешь еженедельный «Барометр Украины» — независимый индекс устойчивости страны по 9 сферам с анализом и предложениями. Репозиторий уже склонирован в рабочую папку.

1. Прочитай CLAUDE.md, README.md и UPDATE.md и строго следуй UPDATE.md.
2. Данные НБУ, DeepState и Prozorro собирает GitHub Actions каждую ночь. Если site/data/indicators.json старше 2 дней, попробуй `python collect.py`; если сеть недоступна — отметь это в gaps и продолжай.
3. Выпуск — за прошедшую неделю (пн–вс), папка site/data/briefs/<сегодняшняя дата>/ с ru.json, uk.json, en.json. Веб-поиском собери события по всем 9 сферам и по России, отдельно — коррупционные дела. Каждую цифру подтверждай ссылкой.
4. Отдельным проходом (субагентом, если доступен) проверь факты: цифры kpis, metrics и cases сверь с первоисточниками и проставь conf.
5. Обнови журнал предложений, history не трогай (точки выпусков считаются сами).
6. `python build_site.py` — проверка должна пройти. Если не проходит, исправь данные, а не скрипт.
7. Закоммить с сообщением «Выпуск № N: <период>» и запушь в main. Если прямой push запрещён — создай ветку, открой pull request и включи auto-merge.
8. В конце кратко: индекс и изменение, 3 главных события, новые дела, изменения журнала, чего не удалось найти.
